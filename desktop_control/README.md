# 基于FPGA的云台目标追踪系统 · 桌面控制台

本目录提供 V8d 配套的电脑控制界面，支持手动角度设置、限位设置、红球自动跟随、停止保持和 PWM 开关。识别与跟随控制运行在高云 FPGA 上，电脑通过串口发送操作指令。

摄像头画面由开发板以 **1280×720 经 HDMI 输出到外接显示器**。此控制台不接收视频，也不提供电脑摄像头预览。硬件连接与 V8d 下载见[快速开始](../docs/QUICKSTART.md)，通信格式见[串口协议](../docs/SERVO_UART_PROTOCOL.md)。

## 安装与启动

需要 Windows、带 Tkinter 的 Python 3.10 或更新版本，以及 `pyserial==3.5`。建议使用 Python 3.12。在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup-servo-ui.ps1
.\Open-Control-Panel.cmd
```

安装脚本会建立本项目的 `.tools/servo-ui-venv`。以后可双击根目录的 `Open-Control-Panel.cmd`。不要复制其他电脑的虚拟环境；换电脑后重新运行安装脚本。正常启动不会连接串口、启用 PWM 或自动改变限位。

只查看模拟操作流程：

```powershell
.tools/servo-ui-venv/Scripts/python.exe -m desktop_control.app --demo
```

演示模式不会打开真实串口，模拟结果不代表实板验收。正常运行无需 Pillow；仅使用 `--screenshot` 保存窗口截图时需要额外安装 Pillow。

## 连接与手动控制

1. V8d 下载完成后，先保持舵机独立 5V 断开。选择开发板当前的 USB 串口，点击“连接设备”，等待固件回复确认。串口号可能变化，不要固定选择 COM12。
2. 确认 PWM 处于关闭状态，点击“应用水平180° / 俯仰±45°范围”，等待板端确认。这一步只更新限位，不会移动舵机；也可根据装配设置更小范围。
3. 确认底座固定、支架和排线有活动余量，再接通舵机独立 5V，点击“启用并回正”。回正为水平 90°、俯仰 0°，两轴指令均为 1500 μs。
4. 输入角度后点击“发送角度”。编辑输入框或滑条不会立即移动舵机。“回正 90° / 0°”返回上述回正位置。

| 轴 | 显示坐标 |
|---|---|
| 水平 | 从云台正面看：左 0°、正前 90°、右 180° |
| 俯仰 | 向上 −45°、平视 0°、向下 +45° |

界面显示的是**舵机控制指令换算的角度，不是实测角度**。三线舵机没有角度回传；设定范围不等于已经测量完整机械行程。重新装配后应先在回正附近核对两轴方向。

固件复位后默认关闭 PWM，并恢复保守限位：水平 72°～108°、俯仰 −3.6°～+3.6°。这是初始软件限位，可按第 2 步显式调整。安装方向保存在本机 `reports/runtime/desktop_control/mount_directions.json`，不会自动迁移到另一台电脑。

## 红球自动跟随

在正常照明、较干净背景下，V8d 已验证红球显示绿框、方块仅显示橙框。**橙框表示候选红色区域，不是已确认的跟随目标。**强逆光、明显反光、手部粘连及目标过小仍可能造成漏检或状态变化；先确认 HDMI 上绿框稳定，再测试运动。

连接成功、应用所需范围并“启用并回正”后，点击“开始红球跟随”。只有收到板端确认，按钮才变为“切回手动并保持”。缓慢移动红球并停住，观察两轴是否让绿框目标靠近画面中心。

“停止跟随 / 保持”退出自动并保持当前指令；“关闭 PWM 输出”停止控制脉冲，**两者都不会切断外部 5V 电源**。若支架卡住、持续明显抖动或排线拉紧，断开舵机独立 5V。短暂遮挡时暂停自动移动，重新锁定后继续；通信中断导致退出自动后，需要明确重新启动跟随。

## 不连接硬件的检查

在项目根目录运行：

```powershell
.tools/servo-ui-venv/Scripts/python.exe -m unittest desktop_control.test_control desktop_control.test_ports desktop_control.test_app -v
```

这三组测试使用模拟设备和端口资料，不打开真实串口。界面测试需要可用的 Tk 图形环境。需要检查窗口能否正常打开、退出时，可运行：

```powershell
.tools/servo-ui-venv/Scripts/python.exe -m desktop_control.app --demo --quit-after 4
```

界面中固件版本来自 PT20 串口协议回复，不能单凭该版本号判断识别算法是否为 V8d；以发布包、下载脚本和位流校验值为准。
