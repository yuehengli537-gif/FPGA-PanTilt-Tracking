# 接线与运行

## 环境与设备

- 高云 Tang Primer 20K + Dock、OV5640 DVP 摄像头、已装好的双轴位置型舵机云台。
- 摄像头使用现场已验证的较短排线；延长线引起的横条属于采集链路问题，不能用滤波修复。
- 开发板由 USB-JTAG 数据线连接电脑；HDMI 接显示器并选对应输入。笔记本普通 HDMI 输出口不能接收视频。
- 舵机使用独立 5V 电源，与开发板共地。按当前约束，PMOD2 的 FPGA B12 为水平 PWM，C12 为俯仰 PWM；通过背面丝印核对位置。舵机原线红色接 +5V、棕色接 GND、橙色接 PWM；延长线必须逐线对应，不按新线颜色盲接。独立 +5V 不接 FPGA 信号针脚。
- Windows、PowerShell 7、Python 3.10+（含 Tkinter）、pySerial 3.5；编译或烧录还需 Gowin 工具及 USB 驱动。

## 先启动图像

本机板卡已经将 V8d 固化到 Flash。正常上电会加载图像程序，无需每次重新下载。

新板或恢复时：断开舵机独立 5V，关闭控制台，连接 USB-JTAG、摄像头和 HDMI。双击 `Download-V8d.cmd` 临时下载，或 `Flash-V8d.cmd` 永久固化。烧录期间保持 USB 和板卡供电稳定。脚本默认工具目录为本机 Gowin 安装目录，其他电脑可以用命令指定：

```powershell
pwsh -File scripts/download-red-ball-contour.ps1 -GowinHome 'D:\Gowin\Gowin_V1.9.11.03_Education_x64'
pwsh -File scripts/flash-red-ball-contour.ps1 -GowinHome 'D:\Gowin\Gowin_V1.9.11.03_Education_x64'
```

两条命令是替代操作，不需要顺序运行。前者只写 SRAM，断电后恢复 Flash 中程序；后者覆盖 Flash 启动镜像，并进行读回校验。首次固化后完整断电（USB、其他供电及 HDMI 均断开），灯灭等 10 秒再重接，不点下载，验证画面自动出现。

发布包：`bitstreams/camera_uart_shape_diag_v8d_20261028.zip`。

## 使用控制台

1. 双击 `Open-Control-Panel.cmd`。首次安装依赖后再启动；也可按 `desktop_control/README.md` 手动安装。
2. 选择实际出现的 USB 串口并连接。本机最近为 COM12，换电脑后可能不同；蓝牙串口不是板卡。
3. 保持 PWM 关闭，点击“应用水平180° / 俯仰±45°范围”，等板端确认。刚开机显示水平72～108°、俯仰±3.6°是保守默认限位。
4. 确认云台固定、排线有余量，接通舵机独立 5V，点击“启用并回正”。回正为水平90°、俯仰0°。
5. 手动模式输入角度后点击“发送角度”；自动模式先确认 HDMI 红球有绿框，再点击“开始红球跟随”。板端确认后按钮变为“切回手动并保持”。
6. 测试结束点击“停止跟随 / 保持”，关闭 PWM，并断开舵机独立 5V。

角度是 PWM 指令的线性换算值，三线舵机没有真实角度回传。水平0～180°、俯仰−45～+45°是可配置命令范围，不是已测完整机械行程。当前安装负俯仰角抬头、正角低头，两轴反向均未勾选；重新安装后须重新核对。

“停止保持”仍可输出保持脉冲，“关闭 PWM”也不等于断开 5V。出现卡阻或排线拉紧时立即断开舵机独立电源。

## 演示场景与常见问题

- 正常光照、背景简洁，红球与方块互不遮挡时观察绿框选择红球；橙框仅表示原始红色候选，不驱动跟随。
- 大面积重叠或逆光时可能拒绝识别；短遮挡暂停，目标重新露出并确认后恢复。
- 串口未出现：检查 USB-JTAG 数据线、Windows 的 USB Serial Converter A/B 和端口状态。不要因此反复改写 Flash。
- 图像横条：先断开舵机 5V；如仍出现，优先核对摄像头排线与接触。插拔摄像头排线前让开发板完全断电。
- 控制台不会显示 OV5640 视频；图像在 HDMI 显示器上。
