# 舵机电脑控制协议 v1

115200 8N1，无硬件流控，固定16字节。请求与回复同结构。

| 字节 | 内容 |
| --- | --- |
| 0..1 | A5 5A |
| 2 | 版本01 |
| 3 | 消息类型 |
| 4 | 序号，回复原样回显 |
| 5 | 请求为0；回复状态位 |
| 6..13 | 8字节负载；uint16采用小端 |
| 14..15 | CRC16-CCITT，初值FFFF、多项式1021，覆盖字节2..13；CRC高字节在前 |

回复flags：bit0输出启用，bit1指令缓动中，bit2曾触发看门狗保持，bit3自动模式（本版恒0）。看门狗标志锁存，查询不清除，成功控制动作才清除。

| 请求 | 负载 | 成功回复 |
| --- | --- | --- |
| 01 HELLO | 0 | 81：ASCII PT20、主版本、次版本、能力位、模式各字节 |
| 02 GET_STATUS | 0 | 90：当前水平/当前俯仰/目标水平/目标俯仰us，4×uint16 |
| 10 SET_TARGET | 水平、俯仰us，后4字节0 | 90 |
| 11 ENABLE | 第1字节0或1，其余0 | 90 |
| 12 HOLD | 0 | 90 |
| 13 HOME | 0 | 90 |
| 14 SET_LIMITS | 水平min/max、俯仰min/max，4×uint16 | 91：当前4个限位 |
| 15 GET_LIMITS | 0 | 91 |
| 20 SET_MODE | 第1字节0手动或1自动，其余0 | 90；本版拒绝自动 |

能力位bit0手动，bit1自动，本版为01。错误E0：负载第1字节错误码，第2字节原请求类型，其余0；码1未知命令、2非法值或限位修改状态错误、3未启用、4模式不支持。

连接仅执行HELLO、GET_LIMITS、GET_STATUS，不发送目标或自动启用。只有收到正确魔数/版本/CRC/序号/能力回复才显示已连接。电脑每250ms查询状态；不自动重试移动命令，不将串口打开视为握手成功。

坏CRC、坏版本、请求flags非0不产生控制；接收半包20ms超时重置解析。主机一次只有一条在途命令，固件正在返回时允许丢弃新请求，主机不得依赖并行回复。

两轴每20ms更新，最大2us/帧。HOLD与看门狗冻结优先于当帧移动。ENABLE1由关闭到开启时完整首脉冲为1500us；重复ENABLE1幂等不突然回中。ENABLE0立即拉低PWM。SET_TARGET/HOME/HOLD在关闭时拒绝。SET_LIMITS只在关闭时接受，每轴500～2500us且包含1500us；越界目标拒绝，不静默截断。

断线1秒后保持当时命令及PWM。重新连接不自动恢复之前目标。电源和实际轴角度不由本协议反馈。
