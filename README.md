# 基于FPGA的云台目标追踪系统

基于高云 Tang Primer 20K、OV5640 摄像头和双轴舵机云台的红球视觉跟随工程。FPGA 完成图像采集、红球检测、目标状态处理及 PWM 控制；电脑控制台用于设置角度和切换手动／自动模式，视频由 HDMI 输出到显示器。

本仓库是 **2026-10-28 V8d 已验收版本的参赛整理版**，仍需在最终交付前补齐视频、技术文档和授权书。原始开发历史保存在[共用开发仓库](https://github.com/JIANJIAN06215/Tang-Primer-20k-camera/tree/feature/b-red-ball-shape)。整理没有改变 FPGA 源码、约束、IP 或已验收位流。

橙框是原始红色区域的诊断框，不是有效追踪目标。当前算法通过颜色和二维轮廓筛选目标，不使用 YOLO；红圆纸片等相似轮廓、强逆光、较大遮挡仍有识别局限。完整机械角度和长期稳定性尚未做统计测量。

## 快速开始

1. 先读 [接线与运行说明](docs/QUICKSTART.md)，开发板接 USB-JTAG、摄像头和 HDMI 显示器。
2. 已固化本版本的板子直接上电；新板临时测试用 `Download-V8d.cmd`，永久固化用 `Flash-V8d.cmd`。下载前断开舵机独立 5V，关闭控制台。
3. 双击 `Open-Control-Panel.cmd`。首次启动需要 Python 3.10+（含 Tkinter）与网络来安装 pySerial。
4. 连接实际 USB 串口，PWM 关闭时应用所需范围，再接通舵机 5V，显式启用／开始跟随。上电不会自动驱动舵机。

命令入口需要 **PowerShell 7**；工具未安装时会提示，不会自动下载或烧录。

## 目录

| 路径 | 内容 |
|---|---|
| `fpga/` | Gowin 工程、RTL、管脚／时序约束、官方 IP 及配置 |
| `algorithm_sim/` | 共享图像运算 RTL、红球检测与联动测试平台 |
| `servo_uart/` | 主工程依赖的 UART RTL 和串口仿真主机模型 |

| `bitstreams/` | 唯一发布的 V8d 位流 ZIP，下载前核验 SHA256 |
| `scripts/` | 构建、测试、控制台、烧录与代码打包入口 |
| `reports/` | V8d 最终仿真、编译和 Flash 实测证据 |
| `docs/` | 使用说明、复现方法、验收边界、来源及提交清单 |

没有收录旧试验固件、失败中间构建、工具安装包、虚拟环境或电脑缓存。保留的高斯／Sobel 等共享文件是工程引用依赖，不能据此理解为它们参与了当前红球判定。

## 编译与验证

完整步骤见 [构建与测试](docs/BUILD.md)。复现当前发布配置请运行 `scripts/build-release.ps1`，它明确启用 `-CameraUart -ShapeDiagnostics`；直接运行通用 `build.ps1` 的默认配置不等于 V8d 发布配置。

已记录 9 项形状短回归、720p 视频以及像素至 UART/PWM 整链仿真通过。最终建立时间 0 违规、最小裕量 +0.188 ns；仍有 22 条摄像头复位移除时间违规，不能称全部时序通过。详细范围见 [验证记录](docs/VALIDATION.md)。

## 参赛材料

按 [提交清单](docs/SUBMISSION.md)准备：H.264 MP4 演示视频、技术 PDF、RAR 全部代码、官方承诺及使用授权书 PDF；海报为选填。

`scripts/package-submission.ps1` 会检查文件和位流指纹，生成真正的 RAR 代码包，排除 `.git`、工具环境和运行缓存。当前快照约数 MB，最终提交前需重新打包；它不是尚未完成的视频或技术报告。
